# 💍 Marriage Biodata Maker

A production-ready React.js web application for creating beautiful marriage biodatas.

## Quick Start

```bash
npm install && npm start
```

Open http://localhost:3000

## Features

- **5 Templates**: Classic, Modern, Minimal, Traditional, Photo Focused
- **Complete Form**: Personal, Education, Family, Contact, Additional sections
- **Custom Fields**: Add / rename / delete fields per section
- **Profile Photo**: Upload with circle / rounded / square shape
- **Background**: Solid colors, gradients, custom image
- **Text Styles**: Font, size, bold, italic, color for each element
- **Live Preview** with zoom control
- **Drag & Drop** section reordering
- **Export**: A4 PDF, PNG, JPG
- **localStorage** persistence: save, edit, delete, duplicate

## Tech Stack

React 18 · Tailwind CSS 3 · Zustand · React Router v6 · html2canvas · jsPDF · @dnd-kit

## Build

```bash
npm run build
```
